# QA SandBox

A personal project built to explore, practice, and experiment with various Quality Assurance tools and proof comparison techniques.

## Overview

This repository serves as a hands-on learning environment to test out QA utilities, build automation scripts, and explore methods for comparing test proof (such as execution logs, baseline outputs, and visual evidence).

## Project Objectives

* Tool Exploration: Hands-on practice with essential QA tools and testing frameworks.
* Skill Building: Develop and refine personal scripts for QA workflow automation.

## Project Status

This is a personal, ongoing learning project focused on tool discovery and practical QA skill development.
