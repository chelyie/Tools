# QA Proof Comparison Utility

A lightweight, personal utility designed to compare Quality Assurance test evidence, baseline outputs, and logs to verify test results.

## Overview

This project provides a fast, structured way to cross-reference test execution proof against expected baselines. Built for personal QA workflows to reduce manual validation time and spot discrepancies automatically.

## Core Functionality

* Proof Verification: Compare logs, text files, or output artifacts side by side.

For Future Development
* Automated Output:* Generate simple comparison summaries for easy reference.
